AI 유튜브 댓글 이상 패턴 분석기
================================

1. 이 폴더를 컴퓨터에 압축 해제합니다.

2. 터미널(Windows PowerShell 또는 명령 프롬프트)을 열고
   이 폴더로 이동합니다.

3. 필요한 패키지를 설치합니다.

   pip install -r requirements.txt

4. API 키 설정 방법은 두 가지입니다.

   방법 A - 가장 간단한 로컬 시험
   --------------------------------
   그냥 앱을 실행하면 왼쪽 사이드바에 YouTube API Key 입력칸이 나타납니다.
   API Key를 입력한 뒤 영상 주소를 넣어 분석하면 됩니다.

   방법 B - Streamlit Secrets
   --------------------------
   .streamlit/secrets.toml.example 파일을 복사하여
   .streamlit/secrets.toml 로 이름을 바꾼 뒤,
   YOUTUBE_API_KEY 값을 본인의 키로 바꿉니다.

   secrets.toml 파일은 GitHub에 올리면 안 됩니다.

5. 사이트 실행

   streamlit run app.py

6. 브라우저에서 자동으로 열리는 주소로 접속합니다.
   보통 다음 주소입니다.

   http://localhost:8501

7. YouTube 영상 주소를 붙여 넣고
   '댓글 분석하기' 버튼을 누릅니다.

주의
----
- 첫 실행에는 AI 모델 다운로드 때문에 시간이 더 걸릴 수 있습니다.
- 결과는 실제 '댓글부대 존재'를 확정하는 것이 아닙니다.
- 시간 집중, 반복 댓글, AI 의미 유사도, 작성자 반복 등의
  이상 패턴을 사람이 다시 검토하도록 돕는 프로젝트 시뮬레이션입니다.
